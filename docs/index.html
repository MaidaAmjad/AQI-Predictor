1. Project overview

AQI-Predictor predicts the US Air Quality Index (AQI) for Lahore, Pakistan (default coordinates 31.5204°N, 74.3587°E). The system combines three offline Python pipelines with one real-time web application.

Data ingestion

Open-Meteo Air Quality API provides current and hourly historical readings (PM2.5, PM10, gases, AQI).

Feature store

Hopsworks stores versioned feature groups with time-series pollution and calendar features.

ML training

Random Forest and Ridge Regression; best model by R² is saved to Hopsworks Model Registry.

Dashboard

Streamlit UI with 10 views: overview, forecasts, charts, health guidance, and more.

4. Project flow (pipelines)

4.1 End-to-end lifecycle

┌─────────────────────────────────────────────────────────────────────────────┐ │ AQI-PREDICTOR DATA & ML FLOW │ └─────────────────────────────────────────────────────────────────────────────┘ [1] BACKFILL (run once or when refreshing history) backfill.py │ ├─► GET Open-Meteo /v1/air-quality (hourly, last 90 days) ├─► process_historical_data() → DataFrame + aqi_change_rate └─► Hopsworks Feature Group "aqi_features" v2 (insert batch) [2] FEATURE PIPELINE (run on schedule / cron) feature_pipeline.py │ ├─► GET Open-Meteo current air quality ├─► compute_features() → single row (time, pollutants, AQI) └─► Hopsworks Feature Group insert (incremental) [3] TRAINING PIPELINE (run after enough data collected) training_pipeline.py │ ├─► Read full feature group from Hopsworks ├─► Train RandomForestRegressor + Ridge ├─► Compare RMSE, MAE, R² → pick best model ├─► joblib.dump → model/{name}.pkl (local) └─► Hopsworks Model Registry "aqi_predictor" [4] STREAMLIT APP (continuous / user-facing) streamlit run app/app/streamlit_app.py │ ├─► Load model "aqi_predictor" v1 from Model Registry ├─► Read feature group v2 (cached 1 hour) ├─► Fetch live current AQI from Open-Meteo ├─► predict_days() → 7-day forecast └─► Render 10 dashboard pages (Plotly charts)

4.2 Pipeline: backfill.py

StepFunctionDescription
1fetch_historical_aqi()Requests hourly data from Open-Meteo for the last 90 days.
2process_historical_data()Builds records with calendar features and aqi_change_rate (delta from previous hour).
3store_in_hopsworks()Logs into Hopsworks, gets/creates feature group, bulk insert() with Kafka timeout option.

Run: python backfill.py

4.3 Pipeline: feature_pipeline.py

StepFunctionDescription
1fetch_aqi_data()Gets current snapshot from Open-Meteo for configured lat/lon.
2compute_features()Extracts pollutants, US/EU AQI, hour/day/month/day_of_week.
3store_in_hopsworks()Appends one row to feature group (default version 1 in pipeline; dashboard uses v2).

Run: python feature_pipeline.py

4.4 Pipeline: training_pipeline.py

StepFunctionDescription
1get_features()Reads feature group version 2 from Hopsworks.
2train_model()80/20 split; trains Random Forest (100 trees) and Ridge; selects best by R².
3save_model()Saves .pkl locally and registers aqi_predictor in Model Registry via mr.sklearn.create_model().

Run: python training_pipeline.py

4.5 Application: streamlit_app.py

StepFunctionDescription
1load_model_and_project()Downloads aqi_predictor v1, loads random_forest.pkl with joblib (cached).
2get_features()Reads historical features for charts and statistics (TTL 3600s).
3get_current_aqi()Live Open-Meteo current readings for dashboard header.
4predict_days()7-day forward predictions using last row’s pollutant values and calendar features.

Run: streamlit run app/app/streamlit_app.py

9. Setup & run

9.1 Installation (Windows)

python -m venv venv
.\venv\Scripts\Activate.ps1
pip install hopsworks --no-deps
pip install -r requirements-windows.txt

9.2 Installation (Linux / macOS)

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

9.3 Recommended execution order

  1. Configure .env with Hopsworks credentials.
  2. python backfill.py — load ~90 days of hourly history.
  3. python feature_pipeline.py — optional ongoing ingestion.
  4. python training_pipeline.py — train and register model.
  5. streamlit run app/app/streamlit_app.py — launch dashboard.

Open the URL shown in the terminal (typically http://localhost:8501).
