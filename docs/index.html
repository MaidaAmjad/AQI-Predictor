1. Project overview

AQI-Predictor predicts the US Air Quality Index (AQI) for Lahore, Pakistan (default coordinates 31.5204°N, 74.3587°E). The system combines three offline Python pipelines with one real-time web application.

Data ingestion

Open-Meteo Air Quality API provides current and hourly historical readings (PM2.5, PM10, gases, AQI).

Feature store

Hopsworks stores versioned feature groups with time-series pollution and calendar features.

ML training

Five regressors (Random Forest, Ridge, Gradient Boosting, Extra Trees, KNN); best by R² is saved to Hopsworks Model Registry.

Dashboard

Streamlit UI with 10 views: overview, forecasts, charts, health guidance, and more.

4. Project flow (pipelines)

4.1 End-to-end lifecycle

┌─────────────────────────────────────────────────────────────────────────────┐ │ AQI-PREDICTOR DATA & ML FLOW │ └─────────────────────────────────────────────────────────────────────────────┘ [1] BACKFILL (run once or when refreshing history) backfill.py │ ├─► GET Open-Meteo /v1/air-quality (hourly, last 90 days) ├─► process_historical_data() → DataFrame + aqi_change_rate └─► Hopsworks Feature Group "aqi_features" v2 (insert batch) [2] FEATURE PIPELINE (run on schedule / cron) feature_pipeline.py │ ├─► GET Open-Meteo current air quality ├─► compute_features() → single row (time, pollutants, AQI) └─► Hopsworks Feature Group insert (incremental) [3] TRAINING PIPELINE (run after enough data collected) training_pipeline.py │ ├─► Read full feature group from Hopsworks ├─► Train 5 models (RF, Ridge, GBR, Extra Trees, KNN) ├─► Compare RMSE, MAE, R² → pick best model ├─► joblib.dump → model/best_model.pkl + metrics.json └─► Hopsworks Model Registry "aqi_predictor" [4] STREAMLIT APP (continuous / user-facing) streamlit run app/app/streamlit_app.py │ ├─► Load latest "aqi_predictor" from Model Registry (+ local fallback) ├─► Load metrics.json → best model name & all 5 model scores ├─► Read feature group v2 (cached 1 hour) ├─► Fetch live current AQI from Open-Meteo ├─► predict_days() → 7-day forecast (best model only) └─► Render 10 dashboard pages (Plotly charts)

4.2 Pipeline: backfill.py

StepFunctionDescription
1fetch_historical_aqi()Requests hourly data from Open-Meteo for the last 90 days.
2process_historical_data()Builds records with calendar features and aqi_change_rate (delta from previous hour).
3store_in_hopsworks()Logs into Hopsworks, gets/creates feature group, bulk insert() with Kafka timeout option.

Run: python backfill.py

4.3 Pipeline: feature_pipeline.py

StepFunctionDescription
1fetch_aqi_data()Gets current snapshot from Open-Meteo for configured lat/lon.
2compute_features()Extracts pollutants, US/EU AQI, hour/day/month/day_of_week.
3store_in_hopsworks()Appends one row to feature group (default version 1 in pipeline; dashboard uses v2).

Run: python feature_pipeline.py

4.4 Pipeline: training_pipeline.py

StepFunctionDescription
1get_features()Reads feature group version 2 from Hopsworks.
2train_models()80/20 split; trains 5 sklearn models; ranks by R²; saves comparison metrics.
3save_model()Saves best .pkl, metrics.json, and registers aqi_predictor in Model Registry.

Run: python training_pipeline.py

4.5 Application: streamlit_app.py

StepFunctionDescription
1load_model_and_project()Downloads latest aqi_predictor (or MODEL_VERSION from .env); loads best_model.pkl and metrics.json; falls back to model/ locally (cached).
2get_features()Reads historical features for charts and statistics (TTL 3600s).
3get_current_aqi()Live Open-Meteo current readings for dashboard header.
4predict_days()7-day forward predictions using last row’s pollutant values and calendar features.

Run: streamlit run app/app/streamlit_app.py

5. Streamlit dashboard

Navigation is a sidebar radio menu. Each page uses Plotly for interactive charts (bundled with Streamlit). The app targets Streamlit 1.57+ on localhost (typical port 8501–8503).

5.1 Overview page (main screen)

10. Setup & run

10.1 Installation (Windows)

python -m venv venv
.\venv\Scripts\Activate.ps1
pip install hopsworks --no-deps
pip install -r requirements-windows.txt

10.2 Installation (Linux / macOS)

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

10.3 Recommended execution order

  1. Configure .env with Hopsworks credentials.
  2. python backfill.py — load ~90 days of hourly history.
  3. python feature_pipeline.py — optional ongoing ingestion.
  4. python training_pipeline.py — train 5 models, save metrics.json, upload to registry.
  5. streamlit run app/app/streamlit_app.py — launch dashboard (use full .py extension).
.\venv\Scripts\Activate.ps1
streamlit run app/app/streamlit_app.py

Open the URL shown in the terminal (e.g. http://localhost:8501 or :8503).

12. Troubleshooting

IssueCauseFix
“Model comparison not loaded” on Overview Dashboard loaded an old registry version without metrics.json, or training upload failed. Run python training_pipeline.py successfully. Press C in Streamlit to clear cache. App now loads latest registry version + local model/metrics.json fallback.
Hopsworks upload error: extra_trees is not a number Non-numeric value in registry metrics dict. Only pass RMSE, MAE, R², R² % to Hopsworks; put model name in description (fixed in current training_pipeline.py).
ModuleNotFoundError: hopsworks Windows build failure for twofish / incomplete install. pip install hopsworks --no-deps then pip install -r requirements-windows.txt
Streamlit shows usage help for .p file Typo in run command. Use streamlit run app/app/streamlit_app.py
Forecast page ValueError on bar colors 8-digit hex colors not valid in Plotly. Uses hex_to_rgba() helper (fixed in app).
Sidebar won’t reopen Header hidden by custom CSS. ☰ button + stExpandSidebarButton integration (fixed in app).
